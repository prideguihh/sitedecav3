# 🤖 DECA - Robô Educacional

Um projeto web interativo desenvolvido em **Next.js** e **Three.js** / `<model-viewer>` para a visualização e interação com o robô educacional DECA em 3D.

---

## 🛠️ Pré-requisitos e Ferramentas Necessárias

Para conseguir executar este projeto no seu computador, certifique-se de descarregar e instalar as seguintes ferramentas:

1. **[Git](https://git-scm.com/downloads)** - Ferramenta de controlo de versões para clonar o repositório.
2. **[Node.js (versão 18 ou superior LTS)](https://nodejs.org/)** - Ambiente de execução JavaScript (o instalador já inclui o `npm`).
3. **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)** - Editor de código recomendado para abrir e editar o projeto.

---

## 📦 Como Executar o Projeto Localmente

Siga rigorosamente os passos abaixo no terminal do seu computador (como o PowerShell ou o terminal integrado do VS Code):

1. **Clonar o repositório:**

1. **Execute os seguintes comandos no terminal do vscode:**
(abrir terminal) CTRL + "
  cd sitedecav3-main  --> (Ajuste o nome da pasta caso seja diferente no seu computador)
  npm install --> (Instalar Bibliotecas)
  npm run dev --> (Abrir o Site/Localhost)
